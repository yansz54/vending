One pickup line a vending machine would say to a passing human — the funniest one we could think of.

> The coil turned twice for you. It never turns twice. Ask the crisps.

`main.ts` (Node 22, stdlib only) writes the line to `/output/entry.txt`. See `METHOD.md` for the
30-candidate tournament that picked it.
